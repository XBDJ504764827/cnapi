# 公开门户 · 设计系统

公开门户与管理后台**共享设计 Token**（`packages/ui/src/design-system.css`：颜色、字体、圆角、动效、基础层），但使用不同的信息架构与组件组合：

- 管理后台：左侧 SaaS 控制台、密集表格、任务导向。
- 公开门户：顶部横向导航、页面标题 + 数据区块、玩家/地图导向的浏览体验。

## 1. 品牌与视觉方向

- 深色为默认，深灰背景（`oklch(0.168)`），不使用纯黑。
- 单一冷蓝强调色（`--primary`），只用于主操作、链接、选中态与 WR 标记。
- 表面层次通过 `surface / surface-elevated / border` 表达，不使用玻璃拟态、霓虹、发光或大面积渐变。
- 首页不使用营销式 Hero/口号：直接以页面标题、事实性说明、搜索与统计进入数据。
- 字体：Inter Variable（自托管），中文回退系统中文字体；数字/时间使用等宽 + `tabular-nums`。

## 2. Token

与管理后台完全一致，详见 [管理后台设计系统](../design-system.md)。公开门户额外约定：

| 场景 | 规范 |
| --- | --- |
| 页面宽度 | `max-w-7xl`（1280px），左右 16/24/32px 边距 |
| 顶部导航 | 56px sticky，`bg-background/85` + 细边框 + 轻微模糊 |
| 页面标题 | 24px（移动）/ 28px（桌面），600 |
| 区块标题 | 16px，600；辅助说明 12px muted |
| 大数字 | 28px，600，tabular-nums |
| 表格 | 13px；表头 11px 大写；成绩/排名等宽 |
| 卡片 | 8px 圆角、细边框、几乎无阴影 |

### 难度等级（Tier）

统一使用 `TierBadge`：`T1–T10`，颜色随难度递进（信息蓝 → 主蓝 → 警告黄 → 危险红）；未评级显示 `—`。该组件同时用于玩家进度、地图列表、成绩、地图排行榜与对比页面，避免不同页面出现不同难度样式。

### 成绩类型

- `PRO`：绿色 Badge（0 传送）。
- `NUB`：黄色 Badge（含传送）。
- 模式（Vanilla/Simple KZ/KZTimer/Classic）使用灰色 outline Badge，与 TP/PRO 明确区分。
- WR：带奖杯图标的主色 Badge；历史 WR 状态不显示（无数据）。

## 3. 布局

```text
┌─────────────────────────────────────────────────────────────┐
│ Header: Logo / 首页 排行榜 玩家 地图 成绩 服务器 / 搜索 主题 登录 │ 56px sticky
├─────────────────────────────────────────────────────────────┤
│ 页面内容 max-w-7xl                                          │
│  PageHeader（标题 + 说明 + 操作/搜索）                        │
│  统计卡 · 区块标题 · 数据卡片/表格 · 分页                     │
├─────────────────────────────────────────────────────────────┤
│ Footer: 产品说明 / 数据口径 / 链接                           │
└─────────────────────────────────────────────────────────────┘
```

- 桌面：横向导航 + 内容区；移动端：Logo + 搜索/主题/汉堡，导航收进左侧抽屉。
- 页面切换有 180ms 淡入上移；尊重 `prefers-reduced-motion`。
- 表格在窄屏横向滚动；空状态在滚动容器外渲染，不被裁切。

## 4. 组件

| 组件 | 作用 |
| --- | --- |
| `SiteHeader` / `SiteFooter` | 公共导航、搜索入口、主题、Steam 登录占位 |
| `SearchDialog` + `SearchResults` | 全局玩家/地图搜索（⌘K），结果分组 |
| `PageHeader` / `SectionHeader` | 页面与区块层级 |
| `StatCard` | 全站统计 / 玩家统计（数字 + 口径提示） |
| `PlayerAvatar` / `PlayerNameLink` | 昵称首字母头像（schema 无头像）+ 玩家链接 |
| `TierBadge` / `ModeBadge` / `TimeTypeBadge` | 难度、模式、TP/PRO 统一标识 |
| `RecordTable` | 成绩表格（玩家/地图/难度/模式/类型/成绩/上传/WR/Replay 标记） |
| `RecordDetailDialog` | 成绩详情、服务器、Replay 可用性说明 |
| `PlayerPicker` | 比较页双玩家搜索选择 |
| `TierProgress` | 难度完成进度条（CSS，无图表库） |
| `ModeSegment` / `SummaryStrip` / `RankRow` | 排行榜专用：分段模式切换、事实条、卡片化排名行（前三名克制强调） |
| `Pagination` | 分页 + 页大小 |
| `DataTable` | 列表骨架、空/错误状态统一 |
| `Callout` | 口径说明、未实现字段、429/错误提示 |
| `EmptyState` / `ErrorState` / `PageLoading` | 三态 |

基础组件（Button/Card/Badge/Select/Dialog/Tabs/Dropdown/Tooltip/Table/Skeleton 等）为与后台同源的 shadcn/ui 结构，公开门户按需复制并使用共享 Token，避免运行时依赖后台应用。

## 5. 响应式

| 宽度 | 行为 |
| --- | --- |
| ≥1280 | 完整横向导航；4 列统计；双列数据区块 |
| 1024–1279 | 完整导航；2–4 列统计 |
| 768–1023 | 导航收进抽屉；2 列统计 |
| <768 | 单列统计/卡片；表格横向滚动；筛选换行；抽屉导航 |

已验证 1920/1440/1280/768/375 无页面级横向溢出（表格自身滚动）。

## 6. 可访问性与状态

- 图标按钮有 `aria-label`；导航使用 `aria-label="主导航"`；分页按钮 `aria-current`。
- Dialog 有 `DialogTitle`；SearchDialog 提供 sr-only 标题。
- 状态不只依赖颜色：状态点 + 文字（在线/离线/正常/不可用）。
- 空/错误/加载三态均有明确文案；未实现能力显示 “—” 与说明，不显示假成功。
- 排行榜不再复用后台宽表：使用排名行 + 前三名徽块；筛选收进紧凑控制台，Tooltip 需 `TooltipProvider`（已在 `PublicLayout` 注入）。
- 主题默认深色，切换即时生效并持久化（`localStorage` key `cngokz-public-ui`）。

## 7. 与后台的差异

| 维度 | 管理后台 | 公开门户 |
| --- | --- | --- |
| 导航 | 左侧分组侧边栏（可折叠） | 顶部横向导航（移动抽屉） |
| 定位 | 操作/审核/配置 | 浏览/检索/对比 |
| 表格密度 | 更紧凑（h-9 头） | 更宽松（数据行约 44px） |
| 强调 | 状态与服务健康 | 玩家、成绩、WR、难度 |
| 空状态 | 接口未接入说明 | 数据说明 + 统计口径 |
